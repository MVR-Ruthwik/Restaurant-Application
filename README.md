# Aromas - Grill Master

A responsive and visually appealing **Restaurant Web App** built using HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile screens.
- **Menu Display**: Showcases menu items with images.
- **Interactive Interface**: Smooth transitions and user-friendly layout.
- **Assets Included**: Includes images like burger wallpapers, icons, and logos.
- **Easy to Customize**: Modify menu items, images, and styles as needed.

## Project Structure

Aromas - Grill Master/
│
├─ Assets/ # Images, logos, and icons
├─ index.html # Main HTML file
├─ style.css # Styling
└─ script.js # JavaScript functionality

## How to Run

1. Clone the repository or download the ZIP.  
2. Open `index.html` in any web browser.  
3. Enjoy the web app locally.
